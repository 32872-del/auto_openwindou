# 自动创建窗口

这是当前统一源码备份。前后端已集成，尚待实机验收；旧 EXE 未更新。

程序是 Python / FastAPI / pywebview 项目。`main.py` 在本机启动 FastAPI，再用 pywebview 打开 `ui/`。依赖范围见 `requirements.txt`。Windows 启动脚本 `启动.bat` 会优先使用本机已有的 Python 3.13，否则回退到 `py -3.13`。

- 前后端已集成。完整 WebView、同事电脑和真实设备链路尚未验收，不能把这份备份视为整体验收通过。旧 EXE 未更新。

仓库里的 `使用说明.md` 是原项目说明。其中提到的发布包、预置凭据和功能清单不在本次备份中。本机最终 EXE 含共用凭据，因此 EXE、发布压缩包和本机交付包都不进入仓库。
