# 自动创建窗口

这是当前源码备份，不是最终功能交付。

程序是 Python / FastAPI / pywebview 项目。`main.py` 在本机启动 FastAPI，再用 pywebview 打开 `ui/`。依赖范围见 `requirements.txt`。Windows 启动脚本 `启动.bat` 会优先使用本机已有的 Python 3.13，否则回退到 `py -3.13`。

## 这份备份的状态

- 后端修改已经落在这份源码里。
- `ui/` 仍是旧界面基线，新前端还没有集成。
- 运行前需要自行安装依赖，并自行准备厂商、代理和其他凭据。本仓库没有这些配置，也不能代替本机环境。
- `打包/` 里的辅助构建脚本还依赖本次未纳入的 `package_check.py` 和 `功能清单.md`。构建资料不完整，不能按现有脚本开箱重新打包。
- `vendor_runtime/` 含已授权纳入的运行时 Python 代码，以及两个原生 DLL。
- `_测试/` 只保留了备份中的三份测试脚本，不是完整测试集。

仓库里的 `使用说明.md` 是原项目说明。其中提到的发布包、预置凭据和功能清单不在本次备份中。
